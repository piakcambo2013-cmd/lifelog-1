# 📔 สมุดบันทึกชีวิตประจำวัน (Daily Life Logger)

ระบบจดบันทึกทุกอย่างในชีวิตประจำวัน — **ค่าใช้จ่าย, เมนูอาหาร, การดื่มน้ำ, การออกกำลังกาย** พร้อมเชื่อมโยงค่าใช้จ่ายเข้ากับทุกกิจกรรมโดยอัตโนมัติ

สร้างด้วย **Flask (ไฟล์เดียว `app.py`)** + **SQLite** + **Tailwind CSS (ผ่าน CDN)** ไม่ต้องติดตั้ง frontend เพิ่มเติม

---

## 🚀 เริ่มต้นใช้งาน

### 1. ติดตั้ง Python
ต้องมี Python 3.8 ขึ้นไป ตรวจสอบด้วยคำสั่ง:
```bash
python --version
```

### 2. ติดตั้ง Flask
```bash
pip install flask
```

### 3. รันโปรแกรม
```bash
python app.py
```

### 4. เปิดใช้งาน
เปิดเบราว์เซอร์ไปที่:
```
http://127.0.0.1:5000
```

> 📁 ตอนรันครั้งแรก ระบบจะสร้างไฟล์ฐานข้อมูล `life_log.db` ขึ้นเองอัตโนมัติในโฟลเดอร์เดียวกับ `app.py` — ข้อมูลทั้งหมดจะถูกเก็บไว้ในไฟล์นี้ ไม่ต้องติดตั้งฐานข้อมูลแยก

## 📝 วิธีใช้งานแต่ละหน้า

### 🏠 แดชบอร์ด
เปิดมาเจอทันทีหน้าแรก แสดง:
- ค่าใช้จ่ายวันนี้ / เดือนนี้
- ปริมาณน้ำที่ดื่มวันนี้ เทียบกับเป้าหมาย 2,000 มล. (แถบความคืบหน้า)
- เวลาออกกำลังกายวันนี้ + แคลอรี่ที่เผาผลาญ
- จำนวนมื้ออาหารวันนี้ + แคลอรี่ที่ได้รับ
- กราฟแท่งค่าใช้จ่ายวันนี้ แยกตามกิจกรรม (ค่าใช้จ่ายทั่วไป/อาหาร/น้ำ/ออกกำลังกาย)
- รายการล่าสุดทั้งหมด 10 รายการ
- ปุ่มลัดสำหรับเพิ่มบันทึกแต่ละประเภท

### 💰 ค่าใช้จ่าย
- กรอกฟอร์มด้านซ้าย: วันที่ เวลา รายการ หมวดหมู่ จำนวนเงิน รายละเอียด แล้วกด **บันทึกค่าใช้จ่าย**
- ตารางด้านขวาจะรวม **ค่าใช้จ่ายจากทุกกิจกรรม** ไม่ใช่แค่ที่กรอกในหน้านี้ — ถ้าคุณกรอกค่าอาหารในหน้า "อาหาร" หรือค่าฟิตเนสในหน้า "ออกกำลังกาย" รายการเหล่านั้นจะมาโผล่รวมที่นี่ด้วยอัตโนมัติ พร้อมป้ายบอกว่ามาจากกิจกรรมไหน (เช่น 🍽️ อาหาร, 🏃 ออกกำลังกาย)
- ใช้ตัวเลือก "เดือน" มุมขวาบนของตาราง เพื่อกรองดูค่าใช้จ่ายของเดือนอื่น
- กล่องซ้ายล่างสรุปยอดรวมแยกตามหมวดหมู่ของเดือนที่เลือก

### 🍽️ อาหาร
- เลือกมื้อ (เช้า/กลางวัน/เย็น/ของว่าง) กรอกชื่อเมนู
- แคลอรี่และค่าใช้จ่ายเป็นช่องไม่บังคับ — ถ้ากรอกค่าใช้จ่าย จะไปรวมในหน้า "ค่าใช้จ่าย" ให้อัตโนมัติ
- ประวัติการกินล่าสุดแสดงด้านขวา ลบรายการได้ด้วยปุ่ม ✕

### 💧 ดื่มน้ำ
- ปุ่มลัดด้านบน (+250 / +350 / +500 / +1000 มล.) กดครั้งเดียวบันทึกทันที ไม่ต้องกรอกฟอร์ม
- หรือใช้ฟอร์มกำหนดเองด้านล่าง สำหรับกรณีพิเศษ เช่น ซื้อน้ำแร่/น้ำดื่มบรรจุขวด (มีช่องค่าใช้จ่ายด้วย)
- แถบความคืบหน้าด้านบนแสดงปริมาณน้ำที่ดื่มวันนี้เทียบกับเป้าหมาย

### 🏃 ออกกำลังกาย
- กรอกประเภทกิจกรรม (มีคำแนะนำอัตโนมัติ เช่น วิ่ง เดิน ปั่นจักรยาน โยคะ) ระยะเวลา และแคลอรี่ที่เผาผลาญ (ไม่บังคับ)
- มีช่องค่าใช้จ่าย สำหรับกรณีมีค่าใช้จ่าย เช่น ค่าฟิตเนส ค่าอุปกรณ์ ค่าคอร์สเทรน

### 🗑️ การลบรายการ
ทุกรายการในตาราง/ลิสต์ประวัติ มีปุ่ม **✕** ท้ายแถวสำหรับลบ ระบบจะขึ้นข้อความยืนยันก่อนลบเสมอ

## 🔗 หลักการเชื่อมโยงค่าใช้จ่ายกับกิจกรรม

ทุกบันทึก (อาหาร, น้ำดื่ม, ออกกำลังกาย) มีช่อง **"จำนวนเงิน"** ของตัวเอง เมื่อกรอกค่าใช้จ่ายในกิจกรรมใดก็ตาม ระบบจะรวมยอดนั้นเข้ากับ:
1. สรุปยอดในหน้า **แดชบอร์ด** (ค่าใช้จ่ายวันนี้/เดือนนี้ และกราฟแยกตามกิจกรรม)
2. ตารางรวมในหน้า **ค่าใช้จ่าย** พร้อมป้ายบอกที่มา

ทำให้เห็นภาพรวมเงินที่ใช้ไปทั้งหมดในชีวิตประจำวัน โดยไม่ต้องจดค่าใช้จ่ายซ้ำสองที่

## 💾 ข้อมูลและการสำรองข้อมูล

- ข้อมูลทั้งหมดเก็บอยู่ในไฟล์ `life_log.db` (SQLite) ที่อยู่โฟลเดอร์เดียวกับ `app.py`
- สำรองข้อมูล: คัดลอกไฟล์ `life_log.db` ไปเก็บไว้ที่อื่นได้เลย
- ล้างข้อมูลทั้งหมด: ปิดโปรแกรมแล้วลบไฟล์ `life_log.db` ทิ้ง (รันโปรแกรมใหม่จะสร้างไฟล์เปล่าให้อัตโนมัติ)
- ย้ายเครื่อง: คัดลอกทั้งโฟลเดอร์ (`app.py` + `life_log.db`) ไปเครื่องใหม่ แล้วรัน `python app.py` ได้เลย

## ⚙️ การตั้งค่าที่ปรับแต่งได้

เปิดไฟล์ `app.py` แล้วแก้ค่าที่ต้นไฟล์ในส่วน "การตั้งค่าเบื้องต้น":

```python
WATER_GOAL_ML = 2000  # เป้าหมายดื่มน้ำต่อวัน (มล.) — แก้เป็นตัวเลขที่ต้องการ
```

และแก้ตัวเลือกหมวดหมู่ได้ที่:
```python
EXPENSE_CATEGORIES = ["อาหาร", "เดินทาง", "ของใช้", "บันเทิง", "สุขภาพ", "บิล/ค่าใช้จ่ายประจำ", "อื่นๆ"]
MEAL_TYPES = ["มื้อเช้า", "มื้อกลางวัน", "มื้อเย็น", "ของว่าง"]
EXERCISE_SUGGESTIONS = ["วิ่ง", "เดิน", "ปั่นจักรยาน", "ยกน้ำหนัก", "โยคะ", "ว่ายน้ำ", "แอโรบิก"]
```

แก้เสร็จแล้ว บันทึกไฟล์ แล้วรัน `python app.py` ใหม่

## 🛠️ ข้อมูลทางเทคนิค

- **Backend**: Flask (Python) — ไฟล์เดียว `app.py`
- **ฐานข้อมูล**: SQLite (`life_log.db`) — ตาราง `entries` เก็บทุกประเภทบันทึกในตารางเดียว
- **หน้าตา/UI**: Tailwind CSS ผ่าน CDN (ไม่ต้อง build, ไม่ต้องติดตั้ง Node.js)
- **Template**: ใช้ Jinja2 `DictLoader` ฝังอยู่ในไฟล์เดียวกัน (extends/blocks ได้ตามปกติ)

## ❓ แก้ปัญหาเบื้องต้น

| ปัญหา | วิธีแก้ |
|---|---|
| `ModuleNotFoundError: No module named 'flask'` | รัน `pip install flask` ก่อน |
| เปิด `http://127.0.0.1:5000` ไม่ได้ | ตรวจสอบว่ารัน `python app.py` แล้วไม่มี error ค้างอยู่ใน terminal |
| พอร์ต 5000 ถูกใช้งานอยู่แล้ว | แก้บรรทัดสุดท้ายของ `app.py` จาก `app.run(debug=True)` เป็น `app.run(debug=True, port=5001)` แล้วเปิด `http://127.0.0.1:5001` แทน |
| ตัวอักษรไทยเพี้ยนตอนดูใน terminal | เป็นเรื่องปกติของบาง terminal (encoding) ข้อมูลจริงในเว็บ/ฐานข้อมูลไม่เสียหาย |
